# Music Genre Classifier

## Overview
The Music Genre Classifier is a machine learning project designed to automatically predict the genre of an uploaded audio file. It encompasses a complete data science pipeline, from audio feature extraction to model training, culminating in an interactive web application. The application processes `.wav` files, extracts key acoustic features, and passes them through multiple trained classification models to predict the corresponding musical genre.

## Methodology

### Feature Extraction
The application utilizes the `librosa` library to extract temporal and spectral features from audio segments. The following features are computed (both mean and variance) to create a numerical profile for each audio track:
* Chroma Short-Time Fourier Transform (STFT)
* Spectral Centroid
* Zero-Crossing Rate
* Mel-Frequency Cepstral Coefficients (MFCCs - 20 coefficients)

### Machine Learning Models
The extracted features are scaled using standard scaling and evaluated across four distinct supervised machine learning algorithms:
* K-Nearest Neighbors (KNN)
* Support Vector Machine (SVM)
* Random Forest Classifier
* Gradient Boosting Classifier

## Repository Structure
* `app1.py`: The main Streamlit web application script. It handles the user interface, file uploading, real-time feature extraction, and prediction generation.
* `train_pipeline.py`: The training pipeline script used to read the dataset, encode labels, scale features, train the four machine learning models, and export the artifacts.
* `features.csv`: The base dataset containing pre-extracted audio features and corresponding genre labels used for training.
* `*.joblib` files: Serialized artifacts generated by the training pipeline, including the models (`knn.joblib`, `svc.joblib`, `rf.joblib`, `gb.joblib`), the data scaler (`scaler.joblib`), and the label encoder (`label_encoder.joblib`).
* `requirements.txt`: The list of Python dependencies required to run the application.

## Usage
1. Open the local web server link provided by Streamlit in your browser. 
2. Upload a `.wav` audio file using the provided file uploader. 
3. Click "Initialize Processing Sequence". 
4. The system will extract the necessary features, apply the scaling transformations, and display the predicted genre alongside the historical accuracy for each of the four models.
